アカウント・通報データの削除依頼

Androidアプリ「1万時間チャレンジ」（ストア掲載予定名：1万時間チャレンジ - 習慣の記録）の共有アカウントと関連データ、匿名で送信した通報データの削除を依頼できます。 アプリを利用できない場合も、以下の窓口から依頼できます。共有機能を有効にしたバージョンを対象とします。

運営：SimpleFlow Apps
原案作成・最終更新日：2026年11月15日
制定日・適用開始日：提供開始前にお知らせします。

本アプリと共有機能は公開準備中です。本ページは、共有機能を有効にするバージョンに向けたご案内です。提供内容や運用の確定に合わせて更新します。

適用開始日、データの保存期間・削除基準、削除依頼への対応目安は、共有機能の提供開始前にお知らせします。

  1. Googleログインで利用した共有アカウント
  2. 匿名で送信した通報データ
  3. 削除する情報と残る情報
  4. 対応の流れと期間

1. Googleログインで利用した共有アカウント

アプリの「設定 → 共有アカウントの削除を依頼」から送信できます。

アプリが使えない場合は、Googleログインに使用したメールアドレスから、contact@simpleflowapps.comへご連絡ください。

件名：1万時間チャレンジの削除依頼

本文：本アプリの共有アカウントと関連データの削除を希望する旨を記載してください。

必要に応じて運営が本人確認のための追加情報を確認します。Googleのパスワードや認証コードを送る必要はありません。

削除依頼のメールを作成

宛先：contact@simpleflowapps.com

件名：1万時間チャレンジの削除依頼

メールソフトが起動しない場合は、上記の宛先・件名を使い、本文に共有アカウントと関連データの削除を希望する旨を記載してください。

2. 匿名で送信した通報データ

アプリの「設定 → 匿名通報データの削除を依頼」から削除用の控えを確認してください。

contact@simpleflowapps.comへ、匿名通報の削除を希望する旨と、画面に表示される「UID:控え」を送信してください。

控えは本人確認のために使います。公開の投稿やSNSには載せないでください。

匿名通報後にGoogleログインへ切り替えた場合も、元の控えを使って匿名通報データだけの削除を依頼できます。端末の控えを失った場合は、その旨を窓口にお知らせください。

3. 削除する情報と残る情報

  • 共有アカウントの削除では、本人の共有投稿、公開用IDとの対応情報、本人が送った通報とカウンター、Firebaseの認証アカウントを削除します。
  • 匿名通報の削除では、控えに対応する匿名通報・カウンター・匿名認証と削除用の控えの照合情報を削除します。別のGoogleログインの共有アカウントや他人の情報は変更しません。
  • 審査記録から本人を識別する項目を除去します。掲載停止を反映する匿名のカードIDは認証UIDとの対応を消し、その掲載週の終了まで保持します。
  • 端末内の習慣・チェック・時間記録、利用者が書き出したCSVは変更しません。端末内の記録は利用者がアプリ・端末から削除し、CSVは保存先から別途削除してください。
  • 本アプリの共有アカウントの削除によって、Googleアカウント自体が削除されることはありません。

4. 対応の流れと期間

運営が依頼内容と本人確認に必要な情報を確認したうえで、削除処理を行います。

削除依頼の本人確認後の対応目安、遅延時のご案内、お問い合わせ情報の保存期間・削除基準は、共有機能の提供開始前に本ページとプライバシーポリシーでお知らせします。

公開一覧から除外しても、配信済みの端末では次の掲載状況の確認、または確認結果の最大24時間の有効期限までカードが残る場合があります。この表示の反映期限は、運営による依頼の受付・本人確認・削除処理の日数とは別です。
